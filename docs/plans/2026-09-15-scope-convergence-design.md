|---|---|---|---|
| 1 | **backlog 背离验收标准** | 唯一未达成的红线（P5）0%，而路线图 §13 把"当前主攻方向"标为批次 Q（多智能体） | 继续加功能不会让作品更可交付 |

## 5. ❄️ 冻结清单与重启条件

> 冻结 ≠ 删除。**每条必须带重启条件**，否则半年后会被重新当成待办挖出来——这正是本轮沉积的成因。
> 冻结项一律不改代码、不排期、不承接部分实现。

| 项 | 冻结理由 | 重启条件 |
|---|---|---|
| **I1–I6** 多租户 / workspace / ACL | 单用户不可演示、不可验证；半成品 ACL 是真实泄露面 | 真实出现第二个用户，或面试岗位明确要求讲多租户 |
| **J2** OTel + Grafana + 告警 | `request_id` + `/health/ready` + 审计已够个人量级 | 出现真实排障需求（线上事故查不动），或岗位明确要求可观测体系 |
| **J4** 审计统一表 | L3 + `/admin/audit` 已覆盖敏感操作 | 企业合规要求 |
| **J6** Secret Manager | 单机 `.env` + Fernet 加密已足够 | 企业落地 / 合规要求 |
| **J7 / C3** Redis、任务队列、S3、Qdrant 集群 | `jobs` 表 + 单体已够；"基础设施可替换"是架构原则，不是待办 | 出现可量化瓶颈（队列深度/延迟有数据支撑） |
| **K1** 连接器管理界面 | K2 前置，无多来源可管 | K2 解冻 |
| **K2** 新连接器（S3/Git/通用目录/SharePoint/Confluence） | **无真实数据源 = 无内容可检索** | 出现真实数据源（如实习/工作环境有 Confluence） |

| **K4** Obsidian 写回 | 读路径未跑满，写回增加对外部系统的副作用面 | 自用中真实出现回写需求，且评估过副作用风险 |

## 6. 关键技术决策

### 6.1 评测进 CI 的取舍（R5）——不宜照搬"进 CI"字面

`rag_eval.py` / `rag_eval_ragas.py` 需要真实嵌入 + Qdrant + LLM judge，而 `AGENTS.md` §8 明令「测试不得触网、不得下载模型」，GitHub Actions 上无法运行。决策：

1. **Jenkins 每日跑评测**（本机有模型缓存，离线加载已优化至 0.13s），结果 + **配置指纹**入库，指标退化则飞书告警；
2. **阈值只卡确定性指标**（空结果率、引用支撑率、双链解析正确率）**+ 不退化约束**（`Recall@K` 不得比 baseline 下降超过设定比例）；
3. **不设绝对语义阈值**（会被随机性打脸）；
4. **GitHub Actions 保持纯单测**，不引入模型依赖。

### 6.2 MCP 形态（R4）

- 按 P0.4 走**本地 stdio + 管理员 `.env` 配置**（行情公开且同源，避开用户级配置带来的 SSRF/凭据/隔离三重复杂度）；
- **MCP 返回视为不可信**（`AGENTS.md` §6.6/§18）：数值夹取（`nav ∈ (0,1e6)`、`change_pct ∈ [-100,100]`）、`nav_date` 非法即丢弃、只取结构化字段；
- **`fund_tool` 包一层**，LLM 不直接见 MCP server（换 server 只改适配器，prompt 不变）；
- **数字类问题不走 RAG**（净值是精确值，语义检索数字 = 幻觉源），R5 补一条防幻觉回归。

### 6.3 trajectory 脱敏（R2）

trajectory 禁落密钥；对话原文按现有日志口径处理，**不新增泄露面**（`AGENTS.md` §15）。新增开关 `AGENT_TRACE_ENABLED`，测试环境默认关闭（§8）。

### 6.4 双引擎一致性（R2/R5，`AGENTS.md` §2）

`Q0.2` 已定 LangGraph 升主干、手写 `Orchestrator` 降为对照基线并**功能冻结**。本路线不新增引擎能力分歧：**新能力一律"做成工具"**（两引擎共享 `ToolRegistry`，加工具成本 ≈ 0）。R5 的对照报告即"何时退回单智能体"的数据依据。

## 7. 每批统一验收门槛

- 后端 `pytest` 全绿且覆盖率 ≥ 80%、`ruff` 全过；前端 `npm test` + `build` 零错误；
- 修复/新功能带防回归测试（先失败后通过）；
- 新增配置三件套齐全（`config.py` + 两份 `.env.example`，关键项加启动校验）；
- 后台任务可开关，测试环境默认关闭；
- 删除一律软删除（`deleted_at`/`deleted_by`），列表/检索已过滤；
- trajectory / MCP / webhook 日志无明文密钥；
- 一功能一分支（`feat/` `fix/`），经批准后合并（§11）。
